# Boldsea — Russian–English glossary

> [!note]
> Terms are aligned to the RU digest wording and the EN translation used in **boldsea_v2_en**.

## Core concepts

| Русский термин                  | English                      | Примечание / Notes                                                                    |
|---------------------------------|------------------------------|---------------------------------------------------------------------------------------|
| событие                         | event                        | Базовая единица модели. / The model’s only primitive.                                 |
| актор / субъект                 | actor                        | Инициирует/фиксирует событие. / Initiates or records an event.                        |
| абсолютный субъект              | absolute subject             | Фиктивный актор для внешней среды/датчиков. / Fictional actor for external causes.    |
| причина (cause)                 | cause                        | Ссылки на события-предшественники. / References to predecessor events.                |
| модель (шаблон)                 | model (template)             | Ссылка на модельное событие, породившее событие. / Link to the producing model event. |
| семантический триплет           | semantic triplet             | `base: type: value` (тип + значение).                                                 |
| граф событий                    | event graph                  | Хранилище/структура всех событий и связей.                                            |
| ориентированный ацикличный граф | directed acyclic graph (DAG) | Граф причинности без циклов.                                                          |
| причинно-следственная связь     | causal dependency            | Рёбра A → B: B зависит от A.                                                          |
| онтология событий               | event ontology               | Онтология, где первичны события и их связи.                                           |
| объектная онтология             | object ontology              | Подход, где первичны объекты и их свойства.                                           |
| сущность / объект               | entity / object              | В Boldsea — проекция множества событий. / Projection of events.                       |
| свойство                        | property                     | Общее: атрибут или отношение.                                                         |
| атрибут                         | attribute                    | Литеральное значение (строка/число/дата).                                             |
| отношение / связь               | relation                     | Ссылка на другой индивид (как “foreign key”, но событийно).                           |
| концепт                         | concept                      | Класс/категория (Document, Person…).                                                  |
| индивид                         | individual                   | Экземпляр концепта.                                                                   |
| конструктивная модель           | constructive model           | Набор “строительных блоков”: concept/individual/property/act…                         |
| модельные события               | model events                 | События-схемы/шаблоны.                                                                |
| генезисные события              | genesis events               | События, вводящие “словарь” примитивов.                                               |
| реификационные события          | reification events           | Конкретные факты предметной области.                                                  |
| действие                        | action                       | Последовательность актов как процесс.                                                 |
| акт                             | act                          | Атомарное действие, меняющее состояние.                                               |

## Execution / runtime

| Русский термин    | English             | Примечание / Notes                                             |
|-------------------|---------------------|----------------------------------------------------------------|
| движок            | engine              | Валидирует ограничения, проверяет условия, генерирует события. |
| механизм запросов | query mechanism     | Язык/подсистема для извлечения знаний из графа событий.        |
| система подписок  | subscription system | Реактивность: отслеживание зависимостей и запуск пересчёта.    |
| реактивность      | reactivity          | Срабатывание “по готовности” (как spreadsheet).                |
| поток данных      | dataflow            | Исполнение по условиям и данным, не по командам.               |
| поток управления  | control flow        | Императивный порядок шагов (противопоставление dataflow).      |
| журнал событий    | event log           | В Boldsea — сама модель является журналом.                     |
| трассируемость    | traceability        | Возможность объяснить “почему произошло”.                      |
| аудит             | audit trail         | Кто/когда/почему создал факт.                                  |

## Constraints / restrictions (ограничения)

| Русский термин           | English          | Примечание / Notes                                       |
|--------------------------|------------------|----------------------------------------------------------|
| условие                  | Condition        | Логическое выражение истинности для возможности события. |
| права / разрешения       | Permission       | Кто (роль/актор) может создать событие/выполнить акт.    |
| множественность          | Multiple         | Можно ли несколько реализаций по одному шаблону.         |
| неизменяемость           | Immutable        | Можно ли менять значение после создания.                 |
| уникальность             | Unique           | Значение должно быть уникально среди событий типа.       |
| уникальный идентификатор | UniqueIdentifier | Значение идентифицирует индивида.                        |
| диапазон значений        | Range            | Ограничение типа/класса/интервала.                       |
| динамический диапазон    | SetRange         | Диапазон/множество вычисляется запросом.                 |
| условие на значение      | ValueCondition   | Доп. проверка на значение (сложнее, чем Range).          |
| вычисляемое значение     | SetValue         | Автовычисление значения (формула/запрос).                |

## Related paradigms / близкие термины

| Русский термин         | English                         | Примечание / Notes                                                      |
|------------------------|---------------------------------|-------------------------------------------------------------------------|
| событийная архитектура | event-driven architecture (EDA) | Boldsea — EDA на семантическом уровне.                                  |
| событийное хранение    | event sourcing                  | Хранение изменений как событий; Boldsea добавляет семантику и dataflow. |
| семантическая сеть     | Semantic Web                    | Триплеты, идентификация, Linked Data.                                   |
| связные данные         | Linked Data                     | Семантический формат данных для интероперабельности.                    |
| граф знаний            | knowledge graph                 | Event graph можно рассматривать как “растущий” knowledge graph.         |
| no-code / low-code     | no-code / low-code              | Логика в данных (события/условия), а не в коде.                         |
| бизнес-правила         | business rules                  | В Boldsea выражаются как ограничения и условия.                         |
